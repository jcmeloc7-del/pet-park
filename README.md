# 毛球公园：宠物社区与好物团购原型

用于演示的响应式网站，支持桌面和手机浏览器，无需安装前端依赖或配置服务器。

## GitHub Pages 部署

代码仓库：<https://github.com/jcmeloc7-del/pet-park>

在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。推送到 `main` 后，仓库内的 `Deploy presentation website` 工作流会自动发布；也可在 Actions 中手动运行。首次开启 Pages 后，如之前的运行失败，请重新运行工作流。

部署成功后，演示地址为 <https://jcmeloc7-del.github.io/pet-park/>。

## 本地预览

在项目目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:4173 。无需安装前端依赖。

已实现宠物档案（猫/狗、品种、体型、年龄）、社区分类与搜索、点赞、发布日常与评论、按类型/年龄/体型筛选推荐、商品详情、购物袋、模拟付款/退款、商家发布/下架商品。

数据仅存当前浏览器 localStorage，尚无真实注册登录、服务器、跨设备同步、图片上传、真实支付、库存、商家资质审核。商家中心为演示入口，生产版必须添加服务端身份验证和权限控制。示例主粮为成年配方，幼年/老年档案不会匹配；推荐是明确规则，未实现营养、健康或医疗推荐。店铺、评价、商品均为虚构演示数据。当前为响应式 Web 原型，可后续迁移至微信小程序或 App。
